# PK Transporters

Next.js App Router website for a Pakistan-based container transport and logistics company.

## Included

- Conversion-focused homepage with sticky CTAs, quote form, WhatsApp/call buttons, trust metrics, service grid, coverage map, testimonials, and FAQs.
- Static SEO landing pages for all service silos and priority city searches.
- Blog engine scaffold for logistics guides, Karachi port topics, import/export, customs clearance, and container transport education.
- Dynamic metadata, canonical URLs, Open Graph/Twitter cards, sitemap, robots, breadcrumbs, FAQ, HowTo, Service, Organization, and LocalBusiness schema.
- Sanity Studio scaffold at `/studio` with schemas for services, city pages, blog posts, testimonials, FAQs, industries, locations, SEO metadata, homepage sections, and contact information.
- Vercel-ready ISR/revalidation route at `/api/revalidate`.

## Setup

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in the Sanity project values before using the Studio in production.
